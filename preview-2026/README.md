# Independent 2026 calendar preview

This folder contains the approved 2026 calendar generated by the astronomy
project for 101 locations. Includes 365 dated pages, festivals, aradhanes,
eclipses and sankramanas. Approved city/year date overrides are retained.
Yajur Upakarma is excluded. Normal Ekadashi messages use the simplified wording.

The existing root website remains unchanged. Open index.html in this folder
to review the new publication. This folder contains generated website files;
the astronomy calculation engine and historical audits remain separate.

## Independent 2026 calendar

The main website now publishes the approved independently calculated calendar for
101 locations and all 365 days of 2026. Approved city/year date adjustments are
retained. Name-only festivals and aradhanes display their names; Ekadashi,
Sankramana, applicable eclipse and Krishna Jayanthi records include approved
public guidance. Yajur Upakarma is excluded.

Website: https://globalpanchanga.github.io/Nitya-Panchanga/

The previous scraped publication remains recoverable from Git history before
this migration. The calculation engine is maintained separately; this repository
contains generated website files.
